5 · 历史信号回放

evaluate.forward_stats 算的不是胜率，而是每个 BUY 信号的前瞻价格路径（E3 决策：不假设买入时点，只做信号质量评估）。

项口径
粒度逐信号（一行一票一确认日），要得到比率须自行 groupby 聚合
基准价base = daily_bar.close @ 信号日；取不到则整条跳过
次日前瞻t1_gap = round(next_open / base - 1, 100, 2)，T+1 相对信号日收盘的高开幅度 %
晋级标记t1_promote = derived_bar.is_limit_up @ T+1，布尔值非比率
窗口极值max_up{h} / max_dd{h}，h 取 3 与 5；窗口不足 h 根则置 None（右删失防护 A4），避免近期信号被截断极值系统性拉小
规则化收益rule_ret，优先级与实盘 exit 对齐：E 退潮清仓 > A 断板开盘
出口族A 断板开盘 / B 断板收盘 / C 两日收盘 / D 半仓 / E 退潮清仓，均为费后收益；费 = 佣金 0.0002 x 2 + 印花 0.0005
落库形态signal_outcome 只保留 T+1 与 T+5 两腿，无 T+3（data/schema.py:141-158）
