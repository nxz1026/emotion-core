## 阶段 1 · 基础设施

**目标**：搭好 Rust crate 和 Python 工具层。

**输出**：
- `src/emotion_core/core/`（Rust crate 骨架，Cargo.toml + lib.rs）
- `src/emotion_core/utils/`（Python：db.py, dates.py, price.py, config.py）
- `src/emotion_core/data/models.py`（数据类型）

**验证**：
- `utils/price.py` 的 `limit_up_price(pre_close)` 与 lkl 的 `utils/price.py:9` **逐分对账**
- 涨停价是 `is_limit_up` 判定的基础，**错一分钱全错**

**依赖**：无

---

## 阶段 2 · 算法核心（Rust）

**目标**：用 Rust 实现全部算法逻辑（**语义照 lkl，逐字不改**）。

**输出**：`src/emotion_core/core/src/` 下 7 个模块：

| 模块 | 职责 | lkl 对应 |
|---|---|---|
| `price.rs` | 涨停价（板块感知） | `utils/price.py` + `derive.py:37-52` |
| `indicators.rs` | 判据（is_limit_up/is_bomb/is_one_word/is_exchange/amplitude）+ 连板 | `derive.py` |
| `state.rs` | 状态机（4 相 + 优先级 + buy_window） | `emotion.py:287` |
| `ladder.rs` | 梯队 + 龙头身份 | `ladder.py` |
| `entry.rs` | 信号 checklist（5 条件 + 1 警告） | `entry.py` |
| `promotion.rs` | 晋级率（双口径） | `promotion.py` |
| `ecosystem.rs` | 生态评级（G1-G4/B1-B5） | `dragon_env.py` |

**验证**（**语义等价的关键保障**）：
1. **连板**：与 lkl 的 `_streaks()`（`derive.py:24`，test oracle）对账——同输入同输出
2. **状态机**：与 lkl 的历史 `market_stat` 对账——2024-01-01 ~ 2026-09-24 的 **661 天逐日对账**
3. **信号**：与 lkl 的 `signal` 表对账
4. **晋级率**：与 lkl 的 `promotion_day` 对账

**依赖**：阶段 1

**依赖**：阶段 2

## 关键纪律

1. **每阶段验证通过再进入下一阶段**——不要跳阶段
2. **算法语义逐字不改**——阶段 2 的 Rust 实现必须与 lkl 对账
3. **对账是照妖镜**——连板对账（`_streaks()`）、状态机对账（661 天 market_stat）、信号对账
4. **备份是防线**——阶段 8 上线前必须有 `pg_dump` 备份
5. **回滚是安全的**——老仓库 + 数据都在，唯一不可逆是删老仓库
