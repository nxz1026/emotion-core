## 2. 五个关键裁决

### 2.1 每日增量用哪个源：东财（快，但 502）vs 新浪（慢，5750 次调用）

| | 东财 clist | 新浪 `stock_zh_a_daily` |
|---|---|---|
| 调用次数 | **1 次分页调用拿全市场** | **逐股 1 次**（约 5,750 次） |
| 实测耗时 | 快 | asel 自述 **约 1 小时** |
| 可靠性 | ⚠️ **对海外 IP 恒 502**（lkl 实测，故加了新浪回退） | 稳定 |
| 覆盖 | 不含北交所（`_EM_FS_ALL_A` 本就无北交所） | **含北交所** |

**奎爷的做法**：东财主源 + 新浪回退（`ingest.py:112-264`），且回退时**过滤 `bj*`** 以保持股票池口径一致
（`ingest.py:185-188` 有完整实测记录：新浪 hs_a 5567 条含北交所 346，剔除后 5221 与 EM total 完全一致）。

**建议**：**沿用奎爷的双源设计**（东财主 + 新浪备），因为：
- 东财一次调用省 5,750 次请求，日更场景优势巨大；
- 502 时自动回退，可靠性有保障；
- 这是奎爷实测踩出来的，不是拍脑袋。

**asel 的 1 小时单源回填保留为"全量重建"路径**，不用于日更。

### 2.2 `pre_close` 怎么来 —— C4 的正确解法

**问题**（实测）：asel 用 `LAG(close)` 重算 `pre_close`，**除权日错 339/192,593 行**（最大偏差 15.36 元）
→ 会让涨停判定与"次日开盘溢价"都算错。

**两条可行路径**：

| 路径 | 来源 | 状态 |
|---|---|---|
| **A · 存列，取源端** | 东财 f18（奎爷的做法） | lkl 已实现，且有 `verify_pre_close` 校验（`ingest.py:770-778`） |
| **B · 用复权因子算** | 新浪 `stock_zh_a_factor(adjust='hfq')` | **asel 已验证公式**（`abandoned-data-sources:82`）：<br>`ref(D) = raw_close(D-1) × hfq_factor(D-1) / hfq_factor(D)`<br>坑：必须过滤 `1900-01-01` 哨兵行 |

**裁决建议**：**存 `pre_close` 列**（照 lkl，这是正确性要求不是风格问题）；
取数**优先东财 f18**，缺失时**用路径 B 的公式补算**（asel 的验证成果正好补上 lkl 的缺口）。

> 这正是"工程实现用 asel"的典型例子：**lkl 的存列决策 + asel 发现的补算公式**。

### 2.3 单位统一到「手」—— 奎爷早有实测记录

**我原以为这是个需要判断的问题，结果奎爷把答案写在代码注释里了**（`ingest.py:189-196`）：

> 单位对齐（这是本回退最容易踩的坑）：新浪 volume 单位是「股」，EM f5 是「手」——
> **必须 /100，否则全市场成交量静默放大 100 倍，不报错、只是数字错。**
> 三方实测 600519.SH 2026-09-23：新浪 3098122 股 = 腾讯 30981 手 = Wind 3098122（Wind 元数据 unit=股）。
> 新浪 amount 单位是「元」，与 EM f6 一致，不换算。

**裁决**：
- **成交量统一到「手」**（奎爷的内部口径，EM f5）
- **换手率统一到「百分数」**（奎爷口径；asel 存的是比值，比值 ×100）
- **`amount` 统一到「元」**（两源一致，不换算）

⚠️ **注意一个副作用**：asel 的时点流通股本是**股**，且它验证过
`turnover == volume_shares / outstanding_share`（容差 1e-4）。
若成交量统一到「手」，换手率计算要相应改（`volume_手 × 100 / outstanding_share_股`），
**否则换手率会静默差 100 倍**。这是同一类坑的第二处。

### 2.4 🚨 北交所：能拿到了，但**加了会改历史数字**（新口径冲突 C7）

**asel 实测**（`abandoned-data-sources:54-63`）：

> `ak.stock_zh_a_daily(symbol='bj920002', ...)` → 562 行，2024-05-30 起
> **新浪支持 `bj` 前缀**；腾讯对 `bj` 报 `KeyError: 'day'`。
> 本次回填已入库 **351 只北交所 / 290,095 行**。

**lkl 的现状**：`config.py:53` 注释自认"情绪计数天然缺北交所"；奎爷 R3 决策是
"家数/炸板率/跌停数/昨涨停表现 = **全市场剔ST次新**；连板高度/梯队/龙头 = 主板"。

**冲突**：如果"全市场"口径现在**含北交所**，那么：
- `limit_up_count` 会变化 → `phase` 判定可能翻转 → **历史所有信号都可能变**

**裁决建议**：**不改**（按决策规则：策略语义照 lkl 原样）。
- 北交所数据**保留在数据层**（asel 已有，不删），供**展示、个股诊断（R2）、未来研究**使用；
- 但**奎爷的历史判定口径冻结为"不含北交所"**，否则 661 天历史全部要重算，而我们无法验证重算结果；
- 标注为 **C7 · 存疑，待有懂策略的人核对**。

> ⚠️ 顺带：北交所涨跌幅是 **30%**，判板口径必须单列（asel 的 `ref_limit_rule` 已含 `bse` 板）。

### 2.5 分钟线：确认无源，不重试

asel 实测（`abandoned-data-sources:33`）：`stock_zh_a_hist_min_em(period='1')` 历史深度不足以覆盖 2010 起；
Wind 2015 无数据、2026-09-17 有 239 条。

**后果**（奎爷 S1 已记录为数据边界）：
- 天地板**不可命名**，只能记 `both_limits_touched`
- 一字板**严格判定不可得**（用 `low == upper_limit`，承认"开 1 秒回封"会误判）
- A 杀**无分时**，只出日线连续变量

与 ADR 0001 的 D3 一致：**不伪造日内精度**。

## 5. Wind 的定位

**Wind 是"用户授权接入的计量源"**，不是免费源 —— 这决定了它的用法：

| 项 | 状态 |
|---|---|
| 能力 | 上市日期 / **带日期的 ST 事件** / 除权除息日 / 自由流通股本 / 资金流向 / 当日涨跌停价 / 涨停筛选 |
| 适配器 | `asel/staging/wind_adapter/`（`wind_client.py` + `wind_sources.py`），**未接生产** |
| 配额管理 | ✅ 已有 `quota_ledger.jsonl` + `seed_quota_ledger.py` + TTL 缓存 |
| 防护 | ✅ `SEARCH_STOCKS_MAX_ROWS = 50` 截断检测；`WindNoDataError` / `QuotaError` 分类 |
| 复权映射 | ✅ `ADJUST_TO_AFTYPE: {0:前复权, 1:后复权, 2:不复权}` |

**建议**：
- **Wind 只用于"免费源拿不到或需要核对"的稀缺数据**（这是 asel 自己定的原则，`plan.md:7`）；
- 优先用 Wind 补 **ST 事件（带日期）** 与 **上市日期** —— 这两项是 `ref_security_status` 的数据来源；
- 保留配额账本（`ops_quota_ledger`）。

## 6. 你要求在这一层定的 P4 / P5

### 6.1 P4 · 历史深度做到哪一年？

**实测结论：这不是数据源问题，是一个配置值问题。**

- 数据源能力：**2010-01-04 起**（asel 已回填 14,359,006 行 / 5,847 只，含 361 只退市股）
- lkl 的 2023-11 起，纯粹因为 `config.DATA_START = date(2024, 1, 1)`（奎爷 **D6 决策**）

**裁决建议：数据层保留 2010 起，判定口径仍从 2024-01-01 起。**

理由（这两件事不冲突，要分开看）：

| | 数据深度 | 判定起点 |
|---|---|---|
| 是什么 | **能力** | **策略口径** |
| 谁定 | 工程 | 奎爷 D6 / F1 |
| 取值 | **2010-01-04 起**（asel 已有，不删） | **2024-01-01 起**（照 lkl，不动） |

**深数据的用途**（不用于改判定）：
1. **个股历史身份**（R2 需求：这只票历史上当过几次龙头）
2. **复权因子**（C4 的 pre_close 补算）
3. **制度规则验证**（创业板 2020-08-24 改革等）
4. **未来研究**（奎爷 F1 说"接受数据不全"，但没禁止我们留数据）

**禁止**：用深数据重算奎爷的历史判定 —— 那会改 661 天的历史数字，而我们无法验证。

> 奎爷 F1 原话：*"回测结论必须显式标注周期覆盖不足一个完整长周期，不得外推为策略长期有效性。"*
> 这句话说明他**知道**数据不够，但选择了不扩 —— 我们保留数据、**不扩判定窗口**，是对他决策的尊重。
