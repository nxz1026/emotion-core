# 决策记录（ADR）

每个需要拍板的口径冲突或架构选择，在这里落一份 ADR。

命名：`NNNN-短标题.md`，编号连续不复用。

模板：

```markdown
# NNNN · 标题

- 日期：
- 状态：提议 / 已接受 / 已废弃
- 阻塞：是 / 否

## 背景
## 选项
## 决定
## 理由
## 影响面（哪些历史数据/页面/下游会变）
```
