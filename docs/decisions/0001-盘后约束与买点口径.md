# 0001 · 盘后约束、买点口径、CPT 接入边界

- 日期：2026-09-26
- 状态：**已接受**
- 阻塞：否

---

## 背景

接手者指出：本系统**不做实时分析，只在每天收盘后分析**，所以只能做到"T 日推荐 → T+1 日购买"。
实时计算由本地另一套 **CPT（缠论）** 分析承担，以后接入，暂不考虑。

这条约束与奎爷原设计一致，不是新增限制：

> `PLAN.md:25` **B 决策 · 产品形态：不做实时，只做盘后复盘 + 建议参考；分钟线仅用于事后还原对照**

实测确认数据边界：

| 事实 | 证据 |
|---|---|
| 全库 41 张表**无任何**分钟/tick/日内价格表 | `information_schema.tables` 扫描 |
| `daily_bar` 纯日频：`code,date,open,high,low,close,pre_close,volume,amount,turnover_rate` | 列清单 |
| 唯一的日内**元数据**在 `limit_pool_em`：`first_seal` / `last_seal` / `bomb_times` | 列清单；但**只有 31 天**数据 |

---

## 决定

### D1 · 系统定位为「盘后事实与推荐」，不承诺实时

- 输入：T 日收盘后的日线数据
- 输出：T+1 日的推荐 + 买点参考 + 复盘报告
- **不承诺**：盘中信号、实时触发、分钟级判定

### D2 · 买点参考只允许用「T 日收盘价可表达」的口径

这是本节最重要的结论。因为**只有 T 日收盘时能算出确切数字的价位，才能叫"具体买点"**：

| 口径 | 价格表达式 | T 日收盘时能否给出**确切数字** | 是否符合策略本意 |
|---|---|---|---|
| **A · 次日开盘买** | 次日开盘价 | ❌ **不可知**（只能给历史溢价分布当预期） | 否（奎爷 `baseline_sim` 的口径演示） |
| **B · 次日打板买** | **T 日收盘价 × 1.1** | ✅ **完全可以**（涨停价在收盘时就已确定） | ✅ **是**（`REQUIREMENTS.md:17`"只在龙头胜出的那一刻**打板**买它"） |
| **C · 次日回踩买** | T 日收盘价 × k | ✅ 可以（k 由历史统计定，如 0.97 / 0.98） | 部分 |

**⇒ 口径 B（打板）是唯一既符合策略本意、又能在 T 日收盘时给出确切价格的买点口径。**

**⇒ 因此 `docs/03` §7 N1 的答案是"必须算口径 B"**，而且口径 B 应当成为**主买点口径**，
口径 A 退化为"负期望对照"，口径 C 作为可选参考。

> 注意：口径 B 给出的是**价格水平**，不是"会自动成交"的承诺。
> 打板需要盘中人工（或交易端）盯盘执行 —— 这是交易桥的职责，不是本系统的职责。

### D3 · 不伪造日内精度（守奎爷 F6 / S1 纪律）

系统**不得**输出它无法计算的日内量：

| 不能算 | 原因 | 处置 |
|---|---|---|
| 次日盘中是否真的封住板 | 无分钟数据 | 只能用**次日日线** `high/close` **事后**判定，且必须标注"事后" |
| 开板了几次 / 累计多久 / 离板多深 | 需分钟线，**无源** | 奎爷 `S1` 已标为**数据边界**，不造数据 |
| `limit_pool_em.bomb_times` 的含义 | 奎爷 `S1`：这是东财**逐笔微观计数**（`zbc`），不等于"完整炸板次数" | 呈现时写 **「开板 N（东财）」**，并注明口径；不参与判据 |
| `first_seal` / `last_seal` | 有值但仅 31 天 | 可作为**打板时点参考**展示，标注样本期 |

### D4 · CPT 接入边界：以交易桥为接缝，现在不设计

- **emotion-core** = 盘后（T 日收盘后 → T+1 推荐与买点参考）
- **CPT（缠论）** = 实时（盘中）
- **天然接缝 = 交易桥**（`trade/user{N}/decisions_YYYYMMDD_HHMMSS.json`）
  - 已是**文件契约 + 多用户 + 停机总闸 + 契约硬校验**，实测在用（`trade/user1/`、`trade/user2/`，含 `consumed/<date>/` 归档）
  - 决策契约 v2：`actions[]` 每行 `action / code / reason / window / exec / volume`
- **现在的要求**（只做这两件，不多做）：
  1. **保持契约可扩展**：`action` 是开放枚举（现有 `BUY` / `SELL` / `SECONDARY`），未来 CPT 可新增动作而不破契约
  2. **不改动交易桥的既有语义**（奎爷 T13 契约 v2 是踩过事故换来的，见 `REQUIREMENTS.md:88-90` 的 09-04 601988 误判 EXCLUDED 事故）
- **明确不设计**：CPT 与 emotion-core 的冲突裁决（例如 CPT 盘中看到机会、而 emotion-core 判定 `buy_window=NONE` 禁买）。
  这是**未来的决策**，现在只记录冲突存在，**不预设规则**。

## 影响面

| 对象 | 影响 |
|---|---|
| 买点参考 | 主口径改为 **打板价 = T 日收盘价 × 1.1**（可给确切绝对价格）；口径 A 作为负期望对照保留 |
| 展示层 | 必须明确标注"盘后生成，T+1 执行"；不得出现任何暗示实时性的文案 |
| 交易桥 | 保留占位（用户 P1 决策）；契约保持可扩展，为 CPT 留接缝 |
| 数据层 | 无分钟数据是**既定边界**，不列入待补数据 |
| 算法层 | 不变（`entry` 5 条件照旧） |
