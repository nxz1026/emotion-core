## 0. 本轮要解决的一个前置歧义

**"市场情绪分析"这四个字，在两个仓库里指的不是同一件事。**

| | lkl | asel |
|---|---|---|
| 状态集合 | `冰点/发酵/高潮/退潮` | `hot/neutral/cold/unknown` |
| 判定结构 | **优先级规则链**（退潮>高潮>发酵>冰点，首个命中定相；无命中**延续昨日**） | **单变量阈值分档**（只看 `limit_up_count`） |
| 输出 | `buy_window`（NONE/STANDARD/ENHANCED）+ `force_liquidate` | 7 项指标 + `state` |
| 性质 | **交易决策**（能不能买、要不要清仓） | **事实摘要**（今天几档、趋势如何、缺多少数据） |
| 阈值 | `CLIMAX_ZT=80` / `ICE_ZT_MAX=40`（无版本号） | `hot_min=80`（巧合相同）/ `cold_max=20`（**不同**） |

asel 全库 `grep 退潮|高潮|发酵|冰点|buy_window|force_liquidate|neg_feelback|phase` = **0 命中**。

> **asel 的情绪层是 lkl 的高潮腿与冰点腿的一维近似，不是同一个东西。**
> 两者**不能互相替代**，也**不能同时对外输出"市场状态"**。
> 这是功能层必须先拍板的第一件事（见 §5 Q2）。

## 1. 粒度约定

为避免后面混用，本轮统一用四个词：

| 词 | 含义 | 例 |
|---|---|---|
| **功能域** | 一组相关能力的集合 | 情绪与结构判定 |
| **能力** | 一句可验收的话：给定输入 → 产出什么 | 给定交易日，输出 `phase` + `buy_window` |
| **产出** | 可被别的层消费的具体东西 | `market_stat` 一行 / 一份 JSON 快照 / 一个页面 |
| **消费者** | 谁用它 | 人（复盘者）/ 交易端 / 研究流程 / 下游算法 |

另需区分**已落地**（有数据或有页面）与**设计有但未落地**（表建了但 0 行、模块写了但零 import）。
后者**不能算作"已有能力"**——asel 里这类占了很大比例。

## 4. 功能层三方对照

### 4.1 真重复（同一功能，两份实现）

| 功能 | lkl | asel | 判定 |
|---|---|---|---|
| 全市场日线获取 | 东财 clist 主源 + 新浪/TDX 回退 | 新浪主源 + 腾讯退市兜底 | ⚠️ **同功能、不同源**；数据可合并（asel 是超集） |
| 涨停/一字判定 | SQL 整数式 | 纯函数 | ⚠️ 同功能两实现，asel 多质量三态 |
| 连板计数 | SQL 窗口 | 布尔运行计数（**逐字移植 lkl**） | 🚨 **口径冲突**：停牌断档 |
| 晋级率 | 5 层 × 双口径 + divergence | 单一总率 + 缺口 | 🚨 **口径冲突**：同一天分子都是 13，分母 44 vs 51 |
| Web 展示 | 16 路由 + 浏览器 JS | 11 路由 + 服务端渲染 | ⚠️ 同功能两实现 |
| 数据质量 | 断档检测（不阻断） | 覆盖率门槛（**硬阻断**） | 🔀 不同维度，**互补** |

### 4.2 仅 lkl 有（14 项，asel 零等价物）

情绪周期状态机（4 相）· `buy_window`/`force_liquidate` · 自适应炸板阈值 · 负反馈/分歧降级 ·
连板梯队与龙头淘汰赛 · 题材聚合 · 生态评级 G1-G4/B1-B5 · 加速事件 A1-A3 ·
买入 checklist · 卖出建议 · **交易桥 + 停机总闸 + 持仓 + 自选** · 13 段复盘报告 ·
告警闭环 + 健康推送 + 修订留痕 · 研究统计栈 17 函数 + 结果回填 + 校准提案 · LLM 策略观察

### 4.3 仅 asel 有（asel 独有能力，lkl 零等价物）

16 年历史深度（lkl 仅 3 年）· 北交所覆盖 · 退市股兜底 · 制度规则化（有效期/新股无涨跌幅/北交所）·
**三态质量语义**（"未知"≠"未涨停"）· 缺口上下界 + `undetermined` · 趋势读数（断点/持平带）·
执行范围 scope + excluded 计数 · 覆盖率硬门槛 · 研究隔离设施 · 复权因子 · 原始响应留存（设计）·
迁移账本 checksum · 回填工具链（监督/验收/对账）· 逐票复盘页 / 时间序列页 / 质量页

### 4.4 一句话总结

**重叠集中在小部分"事实计算"（日线/涨停/连板/晋级率），
lkl 的独有能力集中在"决策与复盘"，asel 的独有能力集中在"数据深度与质量语义"。**
