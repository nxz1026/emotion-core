# 数据源调研结论（已实测验证）

> 验证时间：2026-08-29，验证环境：项目 `.venv`（akshare 1.18.94 / pandas 3.0.5）

## 结论总览

| 排名 | 数据源 | 费用 | 关键字段 | 适用角色 |
|------|--------|------|----------|----------|
| 1 | **AKShare**（东财爬虫） | 免费无 token | 连板数、炸板次数、封板时间、换手率、涨停统计 | **主源**：涨停池 + 日线 |
| 2 | **Tushare Pro** `limit_list_d` | 注册送积分，接口限量 | 涨停价、封板时间、open_times、连板统计 | 备源/交叉校验 |
| 3 | **Baostock** | 免费无需注册 | 日线含 preclose、5/15/30/60 分钟线 | 日线兜底、复权校验 |

## 1. AKShare（推荐主源）✅ 已实测

### 1.1 涨停股池 `ak.stock_zt_pool_em(date='YYYYMMDD')`

实测返回 16 列，**直接覆盖需求文档大部分衍生字段**：

```
序号, 代码, 名称, 涨跌幅, 最新价, 成交额, 流通市值, 总市值,
换手率, 封板资金, 首次封板时间, 最后封板时间, 炸板次数, 涨停统计, 连板数, 所属行业
```

实测样例（2026-08-28，共 82 只涨停）：

```
     代码    名称  连板数  涨停统计  炸板次数   换手率   首次封板时间
0  000017  深中华A    7    7/7      14    25.08    093300   ← 7连板，炸板14次仍回封（强换手）
1  002084  海鸥住工    5    5/5       0     1.04    092500   ← 一字板特征：换手1%、09:25封死
2  002742  冀衡医药    4   10/5       3    41.97    093000
```

- `涨停统计` = "N/M"：M 天内 N 次涨停（用于识别"假连板"）
- `炸板次数` + `换手率` 可直接量化需求中的"换手充分度"（投票交互强度）
- 姊妹接口：`stock_zt_pool_zbgc_em`（炸板未回封池）、`stock_zt_pool_previous_em`（昨日涨停今日表现→晋级率）、`stock_zt_pool_strong_em`（强势池）

### 1.2 日线 `ak.stock_zh_a_hist(symbol, period='daily', adjust='')`

实测列：`日期, 股票代码, 开盘, 收盘, 最高, 最低, 成交量, 成交额, 振幅, 涨跌幅, 涨跌额, 换手率`

- ⚠️ 无 `pre_close` 列 → 用**不复权**数据时 `pre_close = 前一日 close`（shift 计算）；除权除息日需剔除或校验
- 分钟线：`ak.stock_zh_a_hist_min_em(period='1')` 可用（打板点判断，历史深度有限）

### 1.3 风险

- 爬虫接口，东财改版会失效 → 必须做本地缓存（parquet），策略层不直接打网络
- 无 SLA，盘中实时性约 3~10 秒延迟，够"盘后筛选"用，不够高频抢板

## 2. Tushare Pro `limit_list_d`（备源）

- 文档：https://tushare.pro/document/2?doc_id=298
- 字段：`trade_date, ts_code, limit_times(连板数), up_stat(涨停统计), open_times(炸板次数), first_time, last_time, limit(状态)`，数据自 2020 年
- 含官方 `stk_limit` 接口（每日涨跌停价格表）→ **可精确解决 10%/20%/5% 板块差异**
- 限制：单次 2500 条、需注册积分（新用户 500 分，该接口够低门槛）；不提供 ST 统计

## 3. Baostock（日线兜底）

- 免费、无需注册、连接稳定：`bs.login()` → `query_history_k_data_plus`
- 日线字段含 `preclose, close, high, low, open, isST` ← **isST 字段直接满足需求 2.1**
- 分钟线只有 5/15/30/60 分钟，无 1 分钟
- 无涨停池概念数据，需完全自算衍生字段

## 4. 需求字段 → 数据源映射

| 需求字段 | AKShare 涨停池 | AKShare 日线 | Tushare | Baostock |
|----------|:---:|:---:|:---:|:---:|
| open/high/low/close/volume | 部分 | ✅ | ✅ | ✅ |
| pre_close | ❌ | ⚠️ shift 计算 | ✅ | ✅ |
| is_st | ⚠️ 名称过滤 | ❌ | ❌(该接口无ST) | ✅ isST |
| limit_up_price | ⚠️ 自算 | ⚠️ 自算 | ✅ stk_limit | ⚠️ 自算 |
| continuous_limit_days | ✅ 连板数 | 自算 | ✅ limit_times | 自算 |
| 炸板次数（换手强度） | ✅ | ❌ | ✅ open_times | ❌ |
| 封板时间（打板点） | ✅ | ❌ | ✅ | ❌ |
| 1分钟线 | ✅(min_em) | — | 积分较高 | ❌ |

## 5. 待与产品讨论的数据坑

1. **涨停价规则不统一**：主板 10%、创业板/科创板 20%、北交所 30%、ST 5%。需求文档 `round(pre_close*1.1,2)` 只覆盖主板非 ST。→ 建议直接采用 Tushare `stk_limit` 官方表，或按代码段+ST 标志分支计算
2. **一字板判定精度**：日线 `low == limit_up_price` 在"盘中瞬间打开 1 秒又回封"时会误判为一字 → 严格版需分钟线
3. **连板数交叉校验**：自算连板数 vs 东财 `连板数` 字段，两源对账（停牌日处理差异）
4. **历史深度**：东财涨停池约可回溯 2019+；更早年份需 Baostock/Tushare 全市场日线自算

## 实施期实测（2026-08-31，海外 IP，回填落地后）

| 源 | 端点 | 结论 |
|---|---|---|
| baostock | login | ❌ 60s 超时，弃用 |
| 深交所/上交所官网 | stock_info_* | ❌ ConnectionReset |
| EM push2his | kline | ❌ RemoteDisconnected（全历史+单日） |
| EM push2 clist | 列表 | ❌ 502/302 → **✅ push2delay 镜像**（pz 上限100，分页可用） |
| akshare spot_em | 全市场快照 | ❌ 56页×sign 被 reset → 自写 _em_clist |
| 新浪 日K | hq.sinajs | ⚠️ 单发 1.5s 可用；4 并发 throttle 至 60s+ |
| 腾讯 日K | ifzq.gtimg | ⚠️ 0.47s；持续并发后空响应（软限流） |
| **TDX pytdx** | 180.153.18.170:7709 | ✅ **回填最终源**：长连接 0.87s/只，5101只/16min/0失败 |
| EM 三池(akshare) | zt/zb/dt_pool_em | ⚠️ **仅最近 ~10-30 交易日**（ZT 实测 08-17 起有数，ZB/DT 报 30 日上限） |

**架构决定**：情绪五指标全部改由 daily_bar+derived_bar 自算（全市场按板块比例
CASE 判板，剔 ST，次新用 first_bar_date≤max(当日-90d, 豁免边) 代理）；
EM 池降级为「近10日对账 + 梯队换手/炸板补全」用途。

**已知坑**：
1. 除权日 pre_close 偏差：TDX 不复权 bar 的前收=昨收盘，交易所口径=除权参考价
   → 除权日涨停判定可能漂移（~0.1% 行，个股 streak 断点）。backlog：XDXR 修正。
2. 北交所无日线源（TDX 不支持）→ 情绪计数天然缺北交所（池口径也仅近10日）。
3. 换手率历史为近似值：vol×10000/当前流通股本（快照股本，未含增发解禁）。
4. 炸板率口径漂移：自算=收盘终态未封/触板（中位 30.8%）vs EM=盘中曾炸/（封+炸）
   （~16%）→ §1.3 高潮阈值 0.30 需重校准（待裁决）。
