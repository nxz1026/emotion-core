# ADR-0001 出口规则族口径拍板（2026-09-01，奎爷）

## 状态
已采纳（审计三轮 P4-1 从 evaluate._exit_family docstring 迁出）

## 背景
同一 T+1 开盘买入前提下需固定一族出口规则做收益对照；
08-31 对比证据（24 通过信号）：A 中位 -3.20/胜率 29%，
D 中位 +0.45/胜率 54%；A 砍尾快（尾部 -18.5 vs -19.4）但砸低开恐慌点。

## 决策
- A 断板开盘 = 正式口径（rule_ret）
- D 半仓 = 影子口径（signal_outcome.rule_ret_d），
  攒 2-3 个月样本对照后再议转正
- 2026-09-03 审计三轮：rule_ret 改 **E??A**（退潮清仓优先，
  与实盘 exit.suggestions 同优先级），E 单列展示

## 后果
- 出口对照报告五族并列（A/B/C/D/E），转正评估看 D 列样本量
