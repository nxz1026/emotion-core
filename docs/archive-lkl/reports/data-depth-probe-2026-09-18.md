## 1. 顺带修掉一个环境 bug（让可用源从 2 个变 4 个）

`py_mini_racer` 在 aarch64 上加载失败：

```
期望: .venv/lib/python3.13/site-packages/py_mini_racer/libmini_racer.glibc.so   ← 不存在
实际: .venv/lib/python3.13/site-packages/py_mini_racer/armlibmini_racer.glibc.so ← wheel 只带这个
```

aarch64 wheel 的文件名带 `arm` 前缀，而 `_get_lib_path("mini_racer")` 不识别 → 报 `Native library not available`。

**修法**：一条软链
```bash
ln -sf armlibmini_racer.glibc.so libmini_racer.glibc.so
```

**效果**：`py_mini_racer` 恢复（`eval('1+1')` = 2）→ **新浪源与交易日历同时复活**。
→ 可用源：东财（限流） + 腾讯（稳定） + **新浪（稳定、快、带股本带因子）** + 交易所名单/日历。

改动只在 `.venv/`（`.gitignore:5` 已忽略），**repo 工作树未变**（`git status` 干净）。

## 2. T03（除权日误判）解法已验证

v1.0 T03：「除权日原始价大跌 → 不自动计跌停/A杀，收益正确调整」。
现有项目把它登记为 `docs/BACKLOG.md` B3（XDXR 除权修正，未修）。

**解法**：用 `hfq_factor` 事件表重建除权日参考价

```
ref(D) = raw_close(D-1) × hfq_factor(D-1) / hfq_factor(D)
```

**实测（600519，2026-06-26 除息日）**：

| 量 | 值 |
|---|---|
| 6/25 raw close | 1212.10 |
| hfq_factor(6/25 生效，即 2025-12-19 事件) | 8.6771454751862 |
| hfq_factor(6/26 生效) | 8.8825126710204 |
| **推算除权参考价** | **1184.08** |
| 6/26 raw close | 1168.63 |
| **相对参考价涨幅** | **−1.30%** ✅ 正确 |
| 用 raw close 直接算 | −3.59% ❌ 把 2.35% 分红当成亏损 |

→ **除权日误判可彻底修掉**，且顺带得到 `adjustment_factors` 表（v1.0 §4「公司行动/收益复权因子，收益研究必需」）。

## 7. 陷阱记录

1. **同一个 akshare 函数在不同源上行为完全不同**：`stock_zh_a_daily`（新浪）一次给全历史且带股本/因子，但**对退市股直接 `JSONDecodeError`**；`stock_zh_a_hist_tx`（腾讯）能拿退市股，但**按年循环请求**（36 年 = 36 次 HTTP）。**选源必须按数据类型分别测**，不能"用一个源包打天下"。
2. **`py_mini_racer` 的失败不是网络问题，是 wheel 文件名前缀**：aarch64 wheel 带 `arm` 前缀而 loader 不认。**一条软链让两个源复活**——遇到 "Native library not available" 先看 `EXTENSION_PATH` 期望值 vs 实际文件名。
3. **`stock_zh_a_daily` 的 `turnover` 是比值不是百分数**（0.568 = 56.8%），直接当 % 用会差 100 倍。
4. **`hfq_factor` 表里有 `1900-01-01` 哨兵行**（值 1.0），是"首个事件之前"的占位，不是真实事件日——建 `adjustment_factors` 表时必须过滤。
5. **新浪的 `date` 列在 factor 模式下是 `Timestamp`，在 raw 模式下是 `datetime.date`**——同一函数两种 dtype，合并前要统一。
6. **东财日线是间歇性可用**：第一次 600519/2019 成功（118 行 1.1s），之后间隔 25s/40s 连续请求全 `RemoteDisconnected`。**单次成功不能判定源可用**；新浪 12/12 稳定，才是可用的主源。
7. **涨停池要区分"接口挂"和"历史无数据"**：近端 47/89 行正常，历史 0 行——同一函数同样的空返回，语义不同。
