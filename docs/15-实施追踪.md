## 阶段 3 · PyO3 绑定 + 外壳 ⛔

**设计**：`docs/10` §阶段 3 + `docs/11` §2.2

**阻塞项**：

| # | 问题 | 影响 | 解决 |
|---|---|---|---|
| 1 | `domain.Bar` ↔ `rust.Bar` 日期类型 | 所有函数 | `_to_rust_bar` / `_from_rust_bar` |
| 2 | `rust.DerivedBar` / `GroupStats` 无 `#[new]` | 无法从 Python 创建 | Rust 侧加 `#[new]` |
| 3 | `FromPyObject` 缺失 | `Vec<T>` 无法自动转换 | 为每个 `#[pyclass]` 实现 |
| 4 | `isinstance` 检查 | 测试期望 Rust 类型同时是 Python dataclass | `__class__` 欺骗 |
| 5 | Rust `exit_family` 签名被另一 Agent 修改 | 调用不兼容 | 同步签名 |

**切换策略**：解决阻塞后，每个模块 ~30 分钟（转换层 + 测试）。
