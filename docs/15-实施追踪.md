## 阶段 3 · PyO3 绑定 + 外壳 ⛔

**设计**：`docs/10` §阶段 3 + `docs/11` §2.2

**阻塞项**：

| # | 问题 | 影响 | 解决 |
|---|---|---|---|
| 1 | `domain.Bar` ↔ `rust.Bar` 日期类型 | 所有函数 | `_to_rust_bar` / `_from_rust_bar` |
| 2 | `rust.DerivedBar` / `GroupStats` 无 `#[new]` | 无法从 Python 创建 | Rust 侧加 `#[new]` |
| 3 | `FromPyObject` 缺失 | `Vec<T>` 无法自动转换 | 为每个 `#[pyclass]` 实现 |
| 4 | `isinstance` 检查 | 测试期望 Rust 类型同时是 Python dataclass | `__class__` 欺骗 |
| 5 | Rust `exit_family` 签名被另一 Agent 修改 | 调用不兼容 | 同步签名 |

**切换策略**：解决阻塞后，每个模块 ~30 分钟（转换层 + 测试）。

### 顺带修掉：每日定时器时区错位（生产环境）

`emotion-core-daily.timer` 写的是 `OnCalendar=Mon-Fri 17:20`，但**本机时区是 `Etc/UTC`** →
实际在 **01:20 北京时间**触发：此时当天尚未开盘，`today_sh()` 是「新的一天」而
`em_data_date()` 是「最近已完成交易日」，两值必然不等 → **日更链每天都会 FAILED**
（09-27 那次 Persistent 补跑即此情形）。

已加 drop-in `/etc/systemd/system/emotion-core-daily.timer.d/10-timezone.conf`：

```ini
[Timer]
OnCalendar=            # 必须置空重置：OnCalendar 是列表属性，否则两个时刻都会触发
OnCalendar=Mon-Fri 17:20 Asia/Shanghai
Persistent=true
```

核对：`systemctl show emotion-core-daily.timer -p TimersCalendar` →
`OnCalendar=Mon..Fri *-*-* 17:20:00 Asia/Shanghai ; next_elapse=Mon 2026-09-28 09:20:00 UTC`
（= 北京时间 17:20，收盘后）。注意 `[Timer] Timezone=` 在本机 systemd 259 上**不生效**，
时区必须写进 `OnCalendar` 表达式。

### 踩坑记录

1. **晋级率第一版口径错了**：用 `lead(cont_days)` 算「下一次涨停」当分子，1 板算出
   17.5% —— 把停牌间隔和跨段重来混了进去。改成显式取日历次日（与 `promotion.py` 的
   `t.date = 次日` 一致）后是 18.5%，且与算法层逐层精确相等。
2. **PG numeric NaN**：`layer_forward` 的尾部样本没有后续日线 → SQL NULL → pandas NaN，
   而 `r is not None` **挡不住 NaN**（会把 NaN 计入 N 并污染中位数/胜率）。改为
   `math.isfinite` 过滤；这条是单测抓出来的。
3. **psycopg 裸 `%`**：名称模糊搜索一律 `name LIKE %s` + 参数 `f"%{kw}%"`，
   `tests/unit/test_stock_query.py` 有 AST 级守护。
4. **`stock_basic.is_st` 全库为 false**（5221 行；名字带 ST/*ST 的有 201 只）——
   EM clist 502 导致该标志位从未填充。判定层改为**名称兜底**（`is_st_name`），
   否则 ST 股会被当成正常票给出参与建议。
5. **latin-1 请求行**：`BaseHTTPRequestHandler` 按 latin-1 解码请求行，`curl` 直发原始
   UTF-8 的中文名会变乱码 → 404。加了 `_recover_utf8`（能 latin-1 回编码 + UTF-8 解码
   才还原，正常中文不受影响），浏览器与 curl 两条路径都通。
6. **`complete()` 只回字符串**：`LLMClient.complete()` 返回 `str`，取 `reply.text` 会
   `AttributeError`；要 `.model` 就得用 `chat()`。
