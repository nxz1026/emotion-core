## 2026-09-30

### D11: cron 看门狗重启分支补 `sudo -n`
- **决策**：`crontab` 看门狗行改为 `curl -sf --max-time 8 -o /dev/null http://127.0.0.1:8098/ || sudo -n systemctl restart emotion-core-dash >> /home/ubuntu/logs/ec-dash-watchdog.log 2>&1`
- **理由**：cron 是非交互会话，裸 `systemctl restart` 必被 polkit 拒（`Access denied as the requested operation requires interactive authentication`），旧行等于只探测不兜底；`--max-time 8` 防 curl 永久挂起，日志重定向留证
- **验证**：模拟 cron 环境打未监听端口 → 重启分支 rc=0，MainPID 1673194 → 1674630，服务 active，日志 0 字节
- **边界**：进程崩溃仍由 unit 的 `Restart=on-failure` + `RestartSec=10s` 兜（不依赖 polkit）；本行只兜「进程活着但不响应」的挂起场景
- **用户确认**：是
